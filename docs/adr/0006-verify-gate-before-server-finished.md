# 0006. 인증서 검증 게이트를 서버 Finished 처리 전에 둠, 기본값은 검증 활성

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
인증서 검증이 실패한 상태에서 애플리케이션 데이터를 보내면 안 된다(N2). 검증을 끄는 플래그가 있어도 기본값은 검증 활성이어야 한다.

## 결정
- `handshake.c`에서 CertificateVerify를 받은 직후, 서버 Finished를 처리하기 전에 `verify_certificate_chain`을 호출한다. 실패하면 그 자리에서 중단한다.
- `--insecure`는 명시 옵션이고, 켜면 경고를 출력한다.
- `--cafile`이 없으면 검증 실패로 처리한다.

## 대안
- Finished 후 검증: 검증 실패 시 데이터가 나가지 않음을 코드 순서로 보장할 수 없다.
- 기본 검증 끔: N2에 어긋난다.

## 결과
- 장점: 검증 실패 시 클라이언트 Finished와 애플리케이션 데이터가 나가지 않는 것이 코드 순서로 보장된다.
- 단점/감수한 점: CA 번들 없이는 `--insecure` 없이 연결할 수 없다.
