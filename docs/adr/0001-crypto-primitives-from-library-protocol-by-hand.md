# 0001. 암호 원시 연산만 라이브러리, 프로토콜 로직은 직접 구현

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
TLS 1.3 클라이언트를 직접 만들어 핸드셰이크를 배우는 것이 목적이다.
원시 연산을 직접 구현하면 위험하고 학습 목표 밖이다(N3). 반대로 고수준 TLS/X.509 API는 배울 부분을 가린다(N4).

## 결정
- X25519, SHA-256, HMAC-SHA256은 libsodium(`crypto_scalarmult`, `crypto_hash_sha256`, `crypto_auth_hmacsha256_*`)을 쓴다.
- HKDF와 TLS 1.3 키 스케줄은 HMAC 위에 직접 구현하고 RFC 5869/8448 벡터로 검증한다.
- 레코드 층, ClientHello 조립, 상태 머신, DER 파싱, PEM/base64 디코딩도 직접 구현한다.

## 대안
- 전부 직접 구현: 원시 연산 직접 구현은 위험하고 학습 목표 밖이다.
- OpenSSL `SSL_*`, `X509_verify_cert`, EVP KDF: 프로토콜 로직을 대신해 배울 부분을 가린다.

## 결과
- 장점: 프로토콜의 모든 바이트를 직접 다룬다.
- 단점/감수한 점: 교육용 전용이다. README와 시작 배너에 실서비스 사용 금지를 명시한다(N1).
