# 0002. 레코드 층과 핸드셰이크 재조립 버퍼 분리

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
실서버의 Certificate 메시지는 여러 레코드에 걸쳐 오고, 한 레코드에 여러 핸드셰이크 메시지가 오기도 한다.

## 결정
레코드 층(`record.c`)은 레코드 단위로만 읽고 쓴다. 핸드셰이크 메시지는 별도 재조립 버퍼(`handshake_buf.c`)에 쌓아 메시지 경계를 따로 찾는다.

## 대안
- 레코드 1개 = 메시지 1개 가정: 실서버의 단편화와 결합을 처리하지 못한다.

## 결과
- 장점: 메시지가 레코드 여러 개에 걸치거나 한 레코드에 여러 개 와도 같은 경로로 처리한다.
- 단점/감수한 점: 핸드셰이크 메시지는 재조립 버퍼에 한 번 복사한 뒤 처리한다.
